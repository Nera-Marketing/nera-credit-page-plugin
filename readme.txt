Serves the Nera Marketing credit page at the theme's attribution URL while switched on.

== Description ==

**Nera Credit Page** replaces the theme's attribution page with an editable credit page about Nera Marketing building the site.

* Off by default: switch it on in the plugin's settings
* Editable copy, FAQs and links (ACF options)
* WebPage structured data for the credit page

== Installation ==

1. Upload and activate **Nera Credit Page**.
2. Open **Settings** from the plugin's row on the Plugins screen and switch the page on.
